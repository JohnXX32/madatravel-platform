# MadaTravel — plan directeur

Repo : https://github.com/JohnXX32/madatravel-platform

Stack figée : Laravel 13, Filament 4, Inertia+Vue3+Tailwind, SQLite local, PostgreSQL prod.

## Phases

- P0 Fondations : repo, domaine, Filament, Inertia, CI, VPS staging
- P1 Vendre : site FR/EN, catalogue, devis WhatsApp, admin leads
- P2 Opérer : calendrier dispo, tarifs, PDF devis, statuts
- P3 Encaisser : acompte Stripe puis Mobile Money
- P4 Croître : SEO destinations, avis, blog

Critère P1 : un visiteur choisit un 4x4, envoie une demande, WhatsApp s’ouvre, le lead est en base.
